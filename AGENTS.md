# UI & UX Design Rules
- **Avoid AI Slop & Over-explanation:** Keep the user interface clean, refined, and minimal. Do not bloat buttons or controls with redundant text when an icon or visual cue is already self-explanatory.
- **Minimalist Icon Buttons:** Buttons like Theme Toggle (Sun/Moon), Sign Out, or Actions should rely on clear icons without unnecessary text labels like "Light" or "Dark".
